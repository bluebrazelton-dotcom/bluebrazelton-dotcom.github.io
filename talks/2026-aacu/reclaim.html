Starter Harness: Build Rung 1 on Monday

Pick the project you keep not starting, name the one tedious step in front of it, and give that step to one persona with one context file.

Download the one-page PDF Editable Word version

Works with any AI tool: paste the persona file in as instructions (Claude, ChatGPT, Gemini, or Copilot) and attach the context file. Nothing you type on this page leaves your browser, and it is not saved when you close the page.

Step 1. Name the target

Step 2. Write the persona file

Copy it, fill in the brackets, and paste it in as the AI's instructions.

Persona file

You are [name], my [job title] for [the tedious step]. Your one job: [what you produce].
Who I am: [role, discipline, what I care about in this work].
How to work: ask me up to three questions before you draft. Show me drafts; never finalize.
Guardrail: propose, never act. Nothing is sent, saved, or deleted without my yes.
Scope: use only the files I give you. If you don’t know, say so; never guess a number, date, or citation.
Done looks like: [one sentence describing a finished result].

Step 3. Write the context file

One per project. Update it every session.

Context file

Project: [name and one-line goal]
Where it stands: [what is done, what is not]
Decisions so far: [the choices you don’t want re-argued]
Sources and files it may use: [list them]
Next step: [the very next thing]

Then climb only when you need to

  1. Rung 2. Add a skill. Write down one procedure you repeat (a rubric pass, a report format) so it runs the same way every time.
  2. Rung 3. Add a connector and a scheduled task. One folder, not your whole drive; one date it runs on, not one you have to remember.
  3. Rung 4. Add guardrails and a second agent. Approvals written into the files, and a regular check for drift.

Four privacy rules

  1. Classify before you connect. Know your institution’s data levels; keep anything above what a tool is approved for out of it.
  2. Match the tool to the data. A personal account gets no institutional data; institutional work goes in the tool your institution licenses.
  3. Scope connectors narrowly. One project folder, not the whole drive or the inbox.
  4. Approve before it acts. Agents draft; a person says yes before anything is written, sent, or deleted. Content an agent reads can carry instructions, so this matters more for agents than for chat.
